📌 A collection of **Python mini projects** built using **PyQt5** and **Tkinter**.  
These projects are designed for **students, beginners, and developers** who want to **practice Python programming, GUI development, and problem-solving**.  

---

## 📂 Project Categories  

### 🔹 PyQt5 Based Projects  
1️⃣ **Fibonacci Generator**  
   - Generates Fibonacci sequences dynamically.  
   - Learn recursion, iteration, and GUI input/output.  

2️⃣ **Student Grade Tracker**  
   - Track and calculate student grades.  
   - Simulates a database-like system using Python lists/dicts.  

3️⃣ **Geolocation Tracker**  
   - Integrates APIs to fetch location data.  
   - Demonstrates API + GUI integration.  

4️⃣ **Calculator**  
   - A fully functional calculator with PyQt5.  
   - Covers event handling, button signals, and layouts.  

---

### 🔹 Tkinter Based Projects  
1️⃣ **Dice Simulation** 🎲  
   - Simulates a rolling dice using random numbers.  
   - Introduces randomness + GUI basics.  

2️⃣ **Rock Paper Scissors Game** ✊✋✌️  
   - Classic game with GUI interface.  
   - Teaches game logic + Tkinter event handling.

## 🚀 Getting Started  

### 1️⃣ Clone the Repository  
```bash
git clone https://github.com/Shahriyar-Kh/python_mini_Projects.git
cd python_mini_Projects
```

### 2️⃣ Install Dependencies  
```bash
pip install pyqt5
```
*(Tkinter comes pre-installed with Python)*  

### 3️⃣ Run Any Project  
```bash
python Fibonacci_Generator.py
```
